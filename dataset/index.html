§ 1328(f) Dataset — Open Data

Versioned, citable open dataset on § 1328(f) successive-filing patterns. CC BY 4.0 license — free use with attribution.

Status

Dataset assembly is in progress. The first public release will include:

  • Per-district successive-Ch.13 filing counts by year
  • Estimated lookback-bar incidence rates (where docket text supports classification)
  • Pro-se vs. attorney-represented breakdown
  • Plan completion rate among lookback-flagged cases

Source data: BAPCPA Table 6 (Administrative Office), FJC IDB, and targeted PACER docket pulls via CourtListener / RECAP.
